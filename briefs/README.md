# Daily Briefs & Reports Archive

This directory stores all self-contained HTML briefs generated during scheduled trading passes:
- `YYYY-MM-DD-premarket-brief.html` (~8:30am ET)
- `YYYY-MM-DD-open-brief.html` (~9:40am ET)
- `YYYY-MM-DD-close-brief.html` (~3:15pm ET)
- `YYYY-MM-DD-evening-brief.html` (~8:00pm ET)

*Prior report files are immutable historical records and are never modified after generation.*
